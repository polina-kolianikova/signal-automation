# SIGNAL

An operational automation studio, expressed as a physical information system. Electric lime, soft paper, black mechanisms and restrained orange status indicators. Space Grotesk is locally hosted. Large tightly set words occupy the left field. Small monospace labels and ruled sections give the rest a technical rhythm.

A request travels through three visible physical gates. Loose fragments align into a document at intake; the decision and output remain connected to that same object. Scroll provides the story coordinate. The workflow lab is a real deterministic local rule engine, with run, pause and reset, three routes, a log and editable inputs. It never claims to change a connected service.

The lab changes to paper for reading and inputs. The ending changes to dark ink for a practical brief. A calculation shows existing manual hours, with the formula disclosed. Downloading creates an actual local file.

Reference principles: the industrial robot staging seen in Marcelo's reel, Refero's industrial catalogue restraint, and Scroll Cinema's causal transition requirement. Code, geometry, layout and brand are original.
