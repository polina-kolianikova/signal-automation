# SIGNAL

Independent interactive automation studio concept by BlackStack Studio. Static HTML, CSS, JavaScript and native SVG. Use a static HTTP server. All paths support repository-based GitHub Pages.

Run a local sample lead through a value and completeness rule. Incomplete details route to manual review, complete high value requests to sales, and other complete requests to nurture. Pause, resume and reset work locally. The ending form calculates current manual hours and downloads a project brief. There are no connected services or transmitted form values.

Asset notices are in assets/LICENSES.md. The geometry, interface and concept are original project source.

## iPhone Safari composition, October2026

The mobile experience now reserves explicit photographic or live-model frames in normal document flow. It does not move the hero object into arbitrary gaps between text blocks. Header, content, forms and footer share the mobile reading grid; desktop retains its cinematic composition. Exact local static font weights avoid variable-default differences across browser engines. Relevant touch interactions, portrait/landscape transitions and live scene visibility were checked in Playwright WebKit. This is browser emulation, not a physical iPhone test.
